# Наряды

Программа для честного распределения нарядов роты: импорт графика из Excel, автоматическая расстановка с несколькими вариантами на выбор, замена снятого человека и печать графика в Word.

## Запуск

`release/Naryady-1.6.0.exe` — портативная программа, установка не нужна. Работает без интернета.

Данные сохраняются автоматически в `%APPDATA%\Наряды\project.json`. Чтобы перенести график на другой компьютер или передать следующему оператору: кнопка «Сохранить копию проекта» (дискета вверху), на новом месте — «Открыть проект» (папка).

## Как пользоваться

- **Призывы** — люди разбиты на призывы (24, 23…). У каждого: «Авто» — программа распределяет сама; «Вручную» — программа таких людей в наряды не ставит, в замену не предлагает и в норму «человек в сутки» не считает. Настраивается в «Настройках → Люди» и при импорте.
- **Импорт** — загрузить лист «Календарь нарядов» из Excel. Можно выбрать несколько листов (ЛЕТ, ЗИМ) и для каждого — призыв и «Авто/Вручную»; «Добавить к текущим» не трогает уже сделанное. Берутся только ЗН Р, Р, ЗН ДТП, ДТП, У, Г, Л, РГ; прочие буквы (З, П, К, ОСВ…) пропускаются. Свои отметки можно добавить в настройках.
- **Распределить** — выбрать период, нажать «Подобрать варианты». Наведите на вариант — он появится в таблице пунктиром. «Применить» — записать.
- **Ограничения** — в «Настройках → Ограничения» можно объединить людей в группы, которые заступают в ротный наряд только вместе, или задать людей, чьи наряды не должны пересекаться по датам. Правила работают при автоматическом распределении и подборе замен.
- **Запреты по типам** — в «Настройках → Люди», столбце «Нельзя», можно запретить человеку ротный наряд (`Р`) или технопарк (`ДТП`). Запрет действует при генерации, замене и ручной постановке.
- **Госпиталь и лазарет** — при выборе `Г` или `Л` программа спросит, на сколько дней проставить отметку. «Лазарет» работает как «Госпиталь», но в таблице и Word используется буква `Л`.
- **Клик по наряду** — снять с заменой (с причиной: Г, У, РГ, «не ставить»), закрепить, удалить. «Закрепить как наказание» сохраняет наряд при генерации, но не считает его в нагрузку человека: дальше он получает наряды наравне со всеми. Наказание обозначено красной рамкой и буквой «Н».
- **Выделение как в Excel** — протянуть мышью прямоугольник по людям и дням; клик по № — вся строка месяца, по дате — весь столбец; Shift — расширить, Ctrl — добавить ещё участок, Ctrl+A — весь месяц. Внизу появится панель: У, Г, РГ, «не ставить», Л (или клавиши 1–5), «Очистить» (Delete), Esc — снять выделение. Если под заливку попали наряды, программа сразу предложит замену.
- **Печать** — в Word. «Как в Excel»: книжный лист в рамке с листа «График», шапка «12.окт / ПН», строка «24 призыв», серые выходные, «ГК» над нужными числами, подписи и дата. «Цветная таблица» — альбомный лист с цветными нарядами. Неделя, ПН–ПН, две недели или месяц (больше 9 дней — на альбомном листе).
- **Порядок людей** — при импорте берётся с листа «График». Менять — перетаскиванием за ⋮⋮ слева от фамилии (в таблице или в «Настройках → Люди»); там же кнопки «Порядок как в Excel» и «По алфавиту». Порядок один для таблицы и печати.
- **Ctrl+Z / Ctrl+Y** — отменить / вернуть.

## Закрытие и системный трей

При нажатии на крестик появляется вопрос «Вы действительно хотите закрыть приложение?»:

- **Да** — полностью закрыть программу;
- **Нет** — оставить окно открытым;
- **Свернуть в трей** — скрыть окно и оставить программу в системном трее.

Клик по значку в трее восстанавливает окно. Через контекстное меню значка также можно открыть программу или полностью выйти.

## Правила честности

1. Все наряды весят одинаково (вес можно поменять в настройках у каждого наряда).
2. Нагрузка = наряды до таблицы (столбцы «в прошлом месяце» из Excel) + обычные наряды в таблице, кроме отмеченных как наказание. Кто меньше — тот идёт первым, вернувшиеся из госпиталя и РГ догоняют.
3. Без «вилок»: между сменой и следующим заступлением минимум 1 свободные сутки (настраивается).
4. Дополнительно выравниваются: Р/ДТП у каждого, наряды на выходных, равномерность промежутков.
5. ДТП: в субботу заступают на двое суток (до понедельника), в воскресенье на ДТП не заступают.
6. Роли: в ротном наряде всегда 1 дежурный и 2 дневальных (3 человека в сутки), в технопарке не больше одного дежурного. Кто дежурный — «Настройки → Люди», столбец «Роль». Замена снятого — той же роли.

Импортированные и поставленные вручную наряды программа не трогает — только свои (отмечены точкой в углу).

## Если интерфейс тормозит

Программа рисует через D3D11on12: на видеокартах Intel Arc стандартный способ Chromium сбоит и даёт 2–5 кадров/с вместо 110–165.
Если на каком-то компьютере графика при запуске падает, программа сама попробует другой способ при следующем запуске
(выбор хранится в `%APPDATA%\Наряды\render.json`; удалите файл, чтобы начать сначала).

## Для доработки

- Новый вид наряда или отметки — `src/lib/model.js` (`DEFAULT_DUTIES`, `DEFAULT_STATUSES`); отметки можно добавлять и из настроек.
- Что важнее при распределении — веса `WEIGHTS` в `src/lib/planner.js`.

```
npm install
node node_modules/electron/install.js   # если npm не скачал Electron
npm start        # собрать и открыть
npm test         # проверки алгоритма и печати
npm run dist     # собрать release/Naryady-<версия>.exe (версия — в package.json, поле version)
```

Автопроверки окна (ничего не появляется на экране): `NARYADY_HEADLESS=1 NARYADY_PROBE=func-probe.js NARYADY_PERF=out.json npx electron .` — сценарии;
без `NARYADY_HEADLESS` и с `perf-probe.js` — замер кадров (окно откроется, не сворачивайте его).
